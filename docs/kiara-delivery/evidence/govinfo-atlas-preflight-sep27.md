The configured local environment has no private `KIARA_GOVINFO_API_KEY`; the connected `--run` was not executed. The prior public `DEMO_KEY` metadata/source reads do not satisfy this gate.

The new operator requires a private key, checks real GovInfo metadata before writing, then uses a fresh generated Atlas database and tenant to preview and stage one exact source. Its assertions require an encrypted Mongo original exact readback, unverified authority, no coverage, and no search chunk. It prints the generated database, tenant and marker before writes. Normal completion drops that generated database. For an interrupted run, `--cleanup DATABASE TENANT MARKER` verifies the exact marker, expected collections and row ownership, and that the originating process has stopped on the same host before dropping it. This is prepared code, not connected source-intake evidence.

GovInfo [offers a free api.data.gov key](https://www.govinfo.gov/api-signup). A release-owned account/key and explicit operational source selection are still needed. A generated-tenant run would qualify technical intake for one annual publication, not current-law applicability, qualified legal review, customer coverage or production credentials.
