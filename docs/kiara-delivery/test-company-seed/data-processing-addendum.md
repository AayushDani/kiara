# Test–employer data-processing addendum · working draft

Status: synthetic, unsigned draft. Version: 1, 2026-09-28. It must be attached to an identified signed order only after a flow-by-flow role analysis.

## Roles and schedule

For each listed flow, the final schedule must name the parties, data subjects, data categories, purposes, processing instructions, locations, subprocessors, and role of each party. Candidate account and marketplace discovery may differ from employer-directed application delivery. This draft does not assume Test is a processor for every flow.

## Proposed controls

For employer-instructed data processing, Test would use the data only for documented service instructions; apply access controls and encryption; limit personnel and subprocessors; give advance subprocessor-change notice under an agreed interval; assist with verified data requests and incidents; and return or delete data at termination subject to a documented lawful retention exception. The final agreement must specify exact notice intervals, technical measures, audit evidence, transfer terms, breach timing, and exception handling.
