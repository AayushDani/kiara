# Official legal sources for Test review

Checked as public sources on 2026-09-28. This is a **source queue**, not a legal coverage certification. Retain an exact official representation and record source version, publication/effective date, retrieval time, URL, hash, jurisdiction, domain, and reviewer before marking any source reviewed. The current legal API supports bounded GovInfo/eCFR intake; other URLs may require manual retained-source intake or an approved adapter. Do not paste a summary and call it the original.
