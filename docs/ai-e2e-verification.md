## Remaining scope boundaries

Retrieval currently uses exact pinned source passages, not embeddings or Atlas Vector Search. The application supports retained California CCPA provisions through 2026; it does not autonomously acquire new jurisdictional policies. Unsupported scope escalates. The improvement agent can change catalogued prompt/retrieval strategies after provider-backed evaluations; human approval authority, spending limits, source trust and evaluator rules remain protected.

Public founder/lawyer roles and source freshness are simulated. Private supplied-context workflows require separate authentication and a source recheck. Paid audit history is retained; visitor access depends on the signed session. Finalization is internal and does not publish a policy. Email delivery is disabled.
